# ECO-CTRL Project Scope

## Project Overview
ECO-CTRL is an embedded Iot Intelligent occupancy and Energy management and optimization system designed to monitor room conditions, and reduce energy wastage through sensing, data collection and analysis, and automation.

## Problem Statement
Many homes and classrooms waste electricity because appliances remain on even when they are not needed. Existing solutions are often expensive or difficult to customize. ECO-CTRL aims to provide an affordable and intelligentt monitoring system.

## Objectives

- Monitor room conditions
- Detect occupancy
- Estimate energy usage
- Display live data
- Generate smart alerts with logical reasoning

## Version 1 Features 
- ESP32 Microcontroller
- Temperature Sensor
- Motion Sensor
- Light Sensor
- Wi-Fi Communication
- Live Dashboard

## Version 2 Features

- Energy Monitoring
- Relay Automation
- Weekly Reports
- Mobile Dashboard
- Better UI

## Stretch Goals

- TinyML Prediction
- PCB Version
- Solar Powered Version
- Custom Mobile App 

## Success Criteria

The project should be successful if:

- Sensors provide reliable and accurate readings

- Data reaches the dashboard

- Dashboard updates live

- Smart alerts function correctly

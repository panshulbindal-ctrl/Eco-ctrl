# Eco-ctrl
Embedded IoT Energy Management System built using ESP32.

## Status 
Planning phase

## Objective 
Develop an IoT system that measures environmental conditions and electricity usage and reduces energy wastage using ESP32 microcontroller

## Planned features
1. Temperature monitoring
2. Motion detection
3. light detection
4. Energy monitoring
5. Uses a Dashboard and give Smart Alerts

## Timeline
1. Hardware
2. Firmware
3. Dashboard
4. Testing 
5. Final prototype
